# 🐍 Python From Zero

A hands-on, project-based course that takes you from **"I've never written code"** to **building real Python programs**.

Every module has a lesson, runnable examples, exercises, solutions and a mini-project. You'll also learn **Git and GitHub** along the way, because every module is submitted as a Pull Request and reviewed, the same way professional developers work.

---

## 📚 Course Roadmap

| # | Module | What you'll learn | Mini-project |
|---|--------|-------------------|--------------|
| 00 | [Setup](00-setup/) | Install Python, VS Code, Git; use the terminal | Hello GitHub |
| 01 | [Basics](01-basics/) | `print`, variables, data types, input, operators, f-strings | Simple calculator |
| 02 | [Control Flow](02-control-flow/) | `if/elif/else`, loops, `range`, `break`, `continue` | Number guessing game |
| 03 | [Data Structures](03-data-structures/) | Lists, tuples, dictionaries, sets, comprehensions | Contact book |
| 04 | [Functions](04-functions/) | Parameters, return values, scope, `*args`, `**kwargs`, lambdas | Unit converter |
| 05 | [Strings in Depth](05-strings/) | String methods, slicing, formatting, text processing | Word counter |
| 06 | [Files & Errors](06-files-and-errors/) | Reading/writing files, `with`, `try/except`, raising errors | Personal journal |
| 07 | [Modules & Packages](07-modules-and-packages/) | `import`, standard library, `pip`, virtual environments, JSON | Expense tracker |
| 08 | [Object-Oriented Programming](08-oop/) | Classes, objects, methods, inheritance, dunder methods | Bank account system |
| 09 | [Testing & Debugging](09-testing-and-debugging/) | Reading tracebacks, debugger, `pytest` | Test your old projects |
| 10 | [Working with APIs](10-apis/) | HTTP, `requests`, JSON APIs, environment variables | Weather CLI app |
| 11 | [Capstone Project](11-capstone/) | Plan, build and present your own project | Your choice! |

Extra practice projects live in [`projects/`](projects/).

**Suggested pace:** about one module per week. Go slower if you need to. Understanding beats speed.

## 🗂️ How Each Module Is Organised

```
01-basics/
├── README.md      ← The lesson. START HERE.
├── examples/      ← Runnable code demonstrating each concept
├── exercises/     ← Your work goes here (files with TODOs)
└── solutions/     ← Reference answers. Only look AFTER a real attempt!
```

Every module README follows the same format:

1. 🎯 **Learning objectives**: what you'll be able to do
2. 📖 **Concepts**: explanations with small code snippets
3. 🧪 **Examples**: code to run and play with
4. ✍️ **Exercises**: graded ⭐ easy, ⭐⭐ medium, ⭐⭐⭐ challenge
5. 🛠️ **Mini-project**: build something with what you learned
6. ⚠️ **Common mistakes**: errors that catch every beginner
7. 🔗 **Resources**: further reading
8. ✅ **Checklist**: confirm you're ready to move on

## 🚀 Getting Started

1. Follow [SETUP.md](SETUP.md) to install Python, VS Code and Git.
2. Read [CONTRIBUTING.md](CONTRIBUTING.md) to learn the branch → code → Pull Request workflow.
3. Open [00-setup/README.md](00-setup/README.md) and begin!
4. Track your progress in [PROGRESS.md](PROGRESS.md).

### Running code

From the repository root:

```bash
python3 01-basics/examples/01_hello_world.py
```

(On Windows use `python` instead of `python3`.)

## 💬 Getting Help

- Stuck on an exercise? Open a **GitHub Issue** using the *Question* template. Include your code and the error message.
- Try for **20–30 minutes** first: read the error, re-read the lesson, search online. Struggling is where the learning happens.
- No question is a stupid question. 🙂

---

## 🧭 Golden Rules

1. **Type the code yourself.** Don't copy-paste examples; your fingers need to learn too.
2. **Break things on purpose.** Change the examples and see what happens.
3. **Read error messages.** They tell you exactly what went wrong (and on which line).
4. **Commit often.** Small commits with clear messages.
5. **Attempt before peeking.** Solutions are for checking, not copying.
