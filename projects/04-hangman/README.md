# ⭐⭐ Hangman
**Do this after:** Module 05

## Requirements
- Pick a random word from a list
- Show the word as underscores: `_ _ _ _ _`
- The player guesses one letter at a time
- Reveal correct letters; count wrong guesses (max 6)
- Don't penalise guessing the same letter twice
- Show which letters have been guessed
- Win/lose message at the end

## Stretch goals
- ASCII-art hangman drawing that grows with each wrong guess
- Load words from a text file
- Categories (animals, countries, programming languages)
