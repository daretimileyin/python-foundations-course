# ⭐⭐ Quiz Game
**Do this after:** Module 07

## Requirements
- Questions are stored in a `questions.json` file (question, 4 options, correct answer)
- Questions are asked in a random order
- Show the score at the end with a percentage
- Save high scores (name + score) to a JSON file and show the top 5

## Stretch goals
- Categories and difficulty levels
- A time limit per question (`time.time()`)
- Fetch questions from the [Open Trivia DB API](https://opentdb.com/api_config.php) (after Module 10)
